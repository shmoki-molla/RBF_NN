# RBF Neural Network Studio

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=for-the-badge&logo=python)
![GUI](https://img.shields.io/badge/Interface-ttkbootstrap-success?style=for-the-badge)

**RBF Studio** — это мощное десктопное приложение для проектирования, обучения и тестирования **Радиально-Базисных Нейронных Сетей (RBFN)**. Программа предоставляет интуитивно понятный графический интерфейс для решения задач классификации, регрессии и кластеризации без написания кода.

---

## Возможности

1. **Три режима работы:**
    - **Классификация:** Распознавание классов с расчетом вероятностей.
    - **Регрессия:** Предсказание непрерывных значений.
    - **Кластеризация:** Группировка данных без учителя.
2. **Гибкая работа с данными:**
    - Загрузка данных из `.csv` и `.npy`.
    - Автоматическое разделение на выборки (Train/Test).
    - Выбор целевых переменных прямо в интерфейсе.
3. **Тонкая настройка RBF:**
    - Настройка количества центроидов (Neurons).
    - Выбор метода инициализации центров: *K-Means* или *Random*.
    - Управление шириной активации (Spread/Sigma).
4. **Метрики и анализ:**
    - Расчет Accuracy, F1-Score, MSE, RMSE, Silhouette Score.
    - Тестирование на отложенной выборке.
    - *Ручное предсказание для одиночных векторов.
5. **Сохранение:** Полная поддержка сохранения и загрузки обученных моделей (`.pkl`).

## Установка и Запуск

### Предварительные требования
Для работы требуется установленный **Python 3.8+**.

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/rbf-network-studio.git
cd rbf-network-studio
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение.
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
python main.py
```

## Как пользоваться

1.  **Загрузка:** Нажмите **"Train Data"** и выберите CSV файл.
2.  **Цели:** В списке справа ("Целевые переменные") выберите колонку, которую хотите предсказывать (ваш `Y`).
3.  **Подготовка:** Нажмите желтую кнопку **"Подготовить данные"**.
4.  **Настройка:** Выберите тип задачи (например, `classification`) и число центров.
5.  **Обучение:** Нажмите зеленую кнопку **"ЗАПУСТИТЬ ОБУЧЕНИЕ"**.
6.  **Тест:** Используйте панель результатов для проверки точности модели.

## Теория (Кратко)

Сеть радиально-базисных функций (RBF) — это тип искусственной нейронной сети, которая использует радиальные базисные функции в качестве функций активации. Выходом сети является линейная комбинация радиальных базисных функций входных данных и параметров нейронов.

Формула активации нейрона (Гауссова функция):
$$\phi(x) = e^{-\frac{||x - \mu||^2}{2\sigma^2}}$$

Где:
*   $\mu$ — центр кластера (нейрона).
*   $\sigma$ — ширина окна (spread).
